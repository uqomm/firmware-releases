uqomm Config — Privacy policy

uqomm Config is published by UQOMM to set up UQOMM VLAD25 devices.

The app does not collect, store or send any personal information. It has no accounts, no analytics and no advertising.

The app connects to VLAD25 devices over Bluetooth Low Energy or a USB cable, only to read and change the device settings that the user asks for. Those settings stay on the device.

The app downloads the public list of VLAD25 firmware versions from downloads.uqomm.com to tell the user whether a newer version exists. That request does not include any information about the user or the device.

The app keeps two preferences on the computer: the display language and, if the user saves one, a settings template. They never leave the computer and are removed when the app is uninstalled.
